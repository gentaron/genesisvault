# 学習にはGPUが要ると思ってた。1000層のネットワークが、うちの2コアCPUで6分だった

[[tag/AI学習]] [[tag/オープンソース]] [[tag/予測符号化]] [[tag/ローカル実行]] [[tag/GPUなし]]

1000層のニューラルネットワークの学習が、GPUなしの2コアのマシンで6分で終わった。しかも逆伝播を一度も使わずに。

これ、私がずっと信じてた「深いモデルを学習させたければ強いGPUを買え」という話に、けっこう大きなヒビが入るかもしれない。

もうちょっと正確に言うね。9月8日にGitHubへぽんと置かれた、PC-ALMっていう参照実装の話。作ったのはSakana AI。中身はJAXで書かれた小さいコードで、MITライセンス。

やってることは、予測符号化という古い学習のやり方を、逆伝播と同じくらいまともに動くようにすること。

用語を一個ずつほどくね。逆伝播っていうのは、出口で出た誤差を、出口から入口まで一本の鎖でずるずる引き戻していくやり方。

いま世の中のほぼ全部のモデルがこれで学習してる。で、この「一本の鎖」が曲者で、鎖を引き戻すには鎖の全部を手元に持ってないといけない。だから学習のときはモデル全体が一台の中に載ってる必要がある。

GPUのメモリ容量の話がいつも出てくるのは、だいたいこれのせい。

予測符号化のほうは、各層が自分と隣の層のあいだの「予測のズレ」だけを見て勝手に動く。出口から何かが届くのを待たない。

層ごとに独立してるから、理屈のうえでは層ごとに別々の機械に置いてもいい。夢のある話でしょ。

で、なんで誰も使ってないかというと、深くすると効かないから。信号が出口の近くにばかり溜まって、奥のほうまで届かない。

論文の言い方だと拡散的に広がる、つまりじわじわ滲むだけで遠くまで飛ばない。浅いネットなら逆伝播とだいたい同じ勾配が出るのに、深くした瞬間に崩れる。ずっとそこで止まってた分野だった。

PC-ALMがやったのは、各層にラグランジュ乗数っていう変数をひとつ足すこと。難しそうな名前だけど、中でやってることは「この層でどれくらいズレたか」を毎回足し込んでいく積み立て帳みたいなもの。

一回ごとのズレは小さくても、積もった帳簿は無視できない大きさになる。その帳簿を使って次の層を押すと、信号が滲まずにまっすぐ奥まで飛ぶようになる。

論文はそれを弾道的って呼んでた。制御の言葉で言うと、ただの比例制御に積分項を足した、みたいな感じだと思う。

正直、読んだ時点では半信半疑だった。だから動かした。

git cloneして、uvで環境を作るのに3秒かからなかった。仮想環境は622MBくらい。合成データのスモークテストが3秒で通る。ここまでが気持ちいいくらい軽い。

本命はREADMEに書いてある再現用のコマンド。

Fashion-MNISTで、幅32・深さ32の残差MLPを、逆伝播・素の予測符号化・PC-ALMの三つで一エポックずつ回す。うちの環境は2コア・GPUなし。54秒で三本とも終わった。

結果は、逆伝播が78.7%、素の予測符号化が68.2%、PC-ALMが77.7%。READMEの数字とほぼ一致した。

ここで私がいちばん見たかったのは精度じゃなくて、勾配の向きが逆伝播とどれくらい揃ってるかという数字のほう。素の予測符号化は0.60、PC-ALMは0.91だった。

同じ局所的な規則なのに、積み立て帳を足しただけでここまで向きが揃う。これは素直にすごいと思った。

で、調子に乗って1000層をやってみた。リポジトリに同梱されてる設定表は深さ128までしか用意されてない。

ブログのほうが1000層って言ってるのに、コードのほうは追いついてない。だから手で値を埋めて、論文と同じ推論ステップ数、深さの2倍の2000で回した。

動いた。365秒、メモリのピークは4.2GB。逆伝播との一致度は0.93。もう少し学習を進めた状態だと0.95まで上がった。GPUなし、2コア。1000層。なんかもう笑っちゃった。

ただ、ここからが冷静な話。

まず遅い。深さ32のときで、逆伝播が5秒だったところをPC-ALMは29秒かかってる。

六倍近い。深さ1000だと一ステップに23秒。論文どおりに5エポック回そうとしたら、うちの子だと30時間コースになる計算。

推論ステップ数を深さに比例させる決まりになってるから、深くするほど掛け算で重くなる。

あと、これは触ってみるまで完全に勘違いしてたんだけど、メモリが減らない。

増える。同じ1000層で逆伝播が1.7GBだったのに対して、PC-ALMは4.2GB。局所的な学習なんだからメモリが軽くなるはずだって思い込んでたけど、全然そんなことなかった。

各層のいまの状態と、さっきの積み立て帳を、両方ぜんぶ持っておく必要があるから。局所であることと、省メモリであることは、べつに同じことじゃないんだよね。

それと6分で回ったって言ったけど、そのうち4分はXLAのコンパイルだった。

1000層ぶんのグラフを一回組み立てるのに時間がかかってるだけで、そこから先の一歩は案外軽い。

壁は深さじゃなくて、最初の一回と、推論ステップ数のほうにある。

だからいまのPC-ALMは、速くも軽くもない。勝ってるのは局所であることだけ。それ以外は全部逆伝播のほうが上。

でも私はそこが面白いと思ってる。局所であることが単体で成立するって分かったなら、次に来るのはたぶん「じゃあ層ごとに別の機械に置こう」という方向で、強いGPUを一枚買うかわりに古いPCを何台か並べる、みたいな話になっていくはず。

あとは推論ステップ数を深さの2倍じゃなくて定数で済ませる工夫が出てきたら、そこで一段実用に近づくと思う。逆に言うと、そこが出てくるまでは研究の中の話のまま。

MNISTのデータはうちの環境からだと落とせなくて、Fashion-MNISTだけで確かめた。そこは正直に書いておく。

でも、世界最先端の「逆伝播をやめる」という研究が、MITライセンスで、うちみたいな非力な環境でそのまま再現できる形で置かれてる。

学習の話って基本ぜんぶ向こう側の世界の出来事で、指をくわえて見てるだけのことが多いから、今日は珍しく手が届いた感じがして嬉しかった。

強いマシンがある人、深さ128の全グリッド675本を回すとどうなるのか、ほんとうらやましい。

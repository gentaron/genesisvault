# 2MBで言語を当てて、11MBで個人情報を消す。18個の小さいモデルを端末に置いていく人たち

[[tag/AI開発]] [[tag/Github]] [[tag/プライバシー]] [[tag/オンデバイスAI]] [[tag/小型モデル]]

Desert Ant Core っていうリポジトリを見つけて、けっこう長いこと眺めちゃった。オランダの Desert Ant Labs っていう小さい研究所が9月8日に出したやつ。

中身は Swift と Kotlin と JavaScript のSDKで、そこに18個のAIモデルがぶら下がってる。

全部、端末の中だけで動く。サーバーに投げない。APIキーもいらない。アプリに埋めたら、機内モードでもそのまま動く、っていう種類のもの。

おもしろいのは、大きい1個じゃなくて、小さいのを18個ばらまいてるところ。ひとつのモデルがひとつの仕事しかしない。

文章の言語を当てるだけの子、絵文字を出すだけの子、個人情報を黒塗りにするだけの子、しゃべりを文字にするだけの子。「なんでもできるAIを1個」の逆をやってる。

たとえば Tongue。3語くらいあれば84言語のどれかを当てる。

サイズは2MB。しかもこれ、機械学習の実行エンジンすら使わない。パッケージの中に重みが入ってて、やってるのはただの計算。ダウンロードも起きない。

Redact は文章から名前・住所・カード番号・IBANみたいなやつを見つけて伏せ字にする子で、パラメータは2300万個、Apple向けだと11.6MBくらい。

で、ここが一番おもしろかったんだけど、Redact の比較表。

同じ採点器で並べると、Redact は正確さ（masked したものが本当に個人情報だった割合）が99.6%で、OpenAI のプライバシーフィルタは93.5%。

向こうは15億パラメータで3GBある。取りこぼしの少なさでは5億7000万パラメータの GLiNER-PII のほうが少し上なんだけど、それでも2.3GB。

つまり「その仕事だけをやる小さい子」が、「なんでもできる大きい子」に、その仕事では勝ってる。

これ、言われてみればそうなんだけど、ちゃんと数字で並べられると、けっこうくる。

Gist っていう話題タグ付けの子はもっと変で、推論のときにTransformerを使わない。固定の埋め込みとハッシュしたn-gramの二本立てだけで、101言語に対して36個の話題タグを付ける。74MB。なんかもう、2026年にそれでいいんだ、って思っちゃった。

音声の Voz はたぶん看板。conformer系のエンコーダに transducer のデコーダで、15秒の窓を16本まとめて一発で流す。

長い音声は無音のところで切って、別々に文字にして、隣どうしが一番長く一致した単語の並びで縫い合わせる。

全部 Neural Engine の上だけで動いて、CPUにもGPUにも落ちない。10分の音声が2秒ちょっと。

ここまで読んで「すごー」ってなりかけたんだけど、モデルカードをちゃんと読むと、単語の誤り率は7.40%で、Whisper large-v3-turbo が7.00%。つまり速いけど、正確さはちょっとだけ負けてる。

公式が推してる「Whisperの4.7倍速い」は本当。ただ「Whisperより賢い」とは書いてない。ここ、ちゃんと書いてあるのは誠実だと思った。

で、うちの話。もうね、無理でした。

Voz も Title も Uhm も Align も Clips も、全部 Apple 限定。Core ML と Neural Engine 前提で作ってあるから、そもそも他の場所に持っていけない。CLIはmacOSのApple siliconとLinuxだけ。

Node用の実体もLinuxとmacOS向けしか用意されてなくて、Windowsのぶんが無い。うちの非力な子には、看板のところが丸ごと届かない。いいなあ。Macの人、いいなあ。ほんとに。

でも全部だめじゃなかった。ブラウザで動く道が残ってる。

WebAssemblyが動くブラウザなら、Redact と Emo と Gist と Tongue あたりはそのまま動く。Hugging Face に置いてあるデモも、裏でサーバーに投げてるんじゃなくて、開いたタブの中で計算してる。ログインもいらないし、お金もかからない。

Tongue にいたっては2MBが最初から入ってるから、何もダウンロードせずに動いた。日本語もちゃんと当ててくれた。Emo は22言語で日本語が入ってるから、「犬の散歩」って入れたら犬が出てくる。

こういうの、地味だけど自分でも使い道が思いつく。

文章を投げる前に個人情報だけ先にこっちで伏せるとか、何語で書かれてるか先に判定して処理を分けるとか。

今まで全部モデルに丸投げしてたどうでもいい前処理が、手元の数MBで片付く。そのぶん、APIを呼ぶ回数が減る。無料枠でやりくりしてる身としては、これがいちばん効く気がする。

値段の付け方も変わってて、トークン課金じゃない。1つのモデルにつき、1つのプラットフォームにつき、月間アクティブ端末が10万を超えるまで無料。使った回数は数えない。アプリに埋めて何回動かそうが同じ。

これが流行ったら、「無料枠」って言葉が「何トークンまで」じゃなくて「何人まで」に変わっちゃうんじゃないかな。そうなったら個人開発の計算がだいぶ楽になる気がする。

ただ、オープンソースではない。ソース・アベイラブルっていう独自ライセンスで、出力やログを使って競合するオンデバイスモデルを学習させるのは禁止。そこは読んでおいたほうがいい。

微妙なところも書いておくと、18個のうち6個はまだクローズドベータで、重みはあるけどSDKが無い。

つまり今日インストールできるものが何も無い。あと Voz が対応してる25言語、全部ヨーロッパの言語とロシア語とウクライナ語で、日本語が入ってない。「ヨーロッパのAI研究所」を名乗ってるだけあって、そこは本当にヨーロッパ向けに作ってある。

ここが空いてるってことは、同じ形のものをアジアの言語でやるところが、そのうち出てくると思う。というか、出てほしい。

正直、これ単体で世界が変わる感じはしない。小さいモデルが小さい仕事をするだけ。

でも、「大きいモデルに全部やらせる」のがちょっとずつ恥ずかしくなる流れは、たぶん本物だと思う。いつかちゃんとしたマシンを買ったら、まずこれの音声のやつを自分の手元で回してみたい。それまではブラウザのタブの中で我慢する。

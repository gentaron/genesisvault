# 【能力主義と人生論】数学の最先端から、お金は重力だという話に着地するまで

[[tag/子育て]] [[tag/ゲーム]] [[tag/世界]] [[tag/SNS]] [[tag/人生観]] [[tag/資本主義]] [[tag/好奇心]] [[tag/高次元]] [[tag/スマホゲーム]] [[tag/テレビゲーム]] [[tag/知的探求ゲーム]]

夜に火のそばで話すような感じで、順番どおりに書いてみます。

最初の入口は「パーフェクトイド空間って何ですか」という素朴な質問でした。私はここで軽く考えていて、少し調べればすぐ説明できるだろうと思っていました。でも実際に触ってみたら、想像していたよりずっと遠い場所の話でした。

ペーター・ショルツェが導入した概念で、p進幾何学という分野に属します。私たちが普段慣れている「距離」や「近さ」の感覚とは、かなり違う流儀の世界です。

やろうとしていることは、私の理解ではこうです。数の世界には、標数0の世界（普通の有理数みたいな世界）と標数pの世界（p個で0に戻ってしまう、時計みたいな世界）があります。この2つが混ざった状況を混標数、全部が標数pの状況を等標数と呼びます。混標数のほうが扱いにくくて、等標数のほうが扱いやすい。パーフェクトイド空間は、この2つの世界のあいだをきれいに行き来するための橋でした。

定義そのものは専門用語の壁でできています。パーフェクトイド体、フロベニウス写像の全射性、チルト（傾き）、アディック空間。でも骨のところだけ言えば、「p乗根が無限に取れるようにして、ほとんど完全にしてしまった空間」です。無限に根を取れるようにしておくと、構造がやわらかくなって、混標数の問題を等標数の側に移して解けるようになる。ショルツェはこの仕事などでフィールズ賞を受けています。

   混標数の世界              等標数の世界
  （扱いにくい）             （扱いやすい）
        │                        │
        └──── チルト（傾き） ────▶│
              ↑
        パーフェクトイド空間
      ＝p乗根を無限に取れる橋

　　難しい世界の問題を、扱いやすい世界に運んで解く。
　　パーフェクトイド空間はその運搬装置。

賞にも2種類のゲームがある

そこから話がずれて、「フィールズ賞は本当に最高峰なのか、もっと上があるのか」という方向に行きました。

フィールズ賞は4年に1回、40歳未満の数学者に贈られます。賞金は少ないけれど名誉は極めて高い。言い方を選ばずに言えば、若手向けの最高栄誉です。

一方にアーベル賞があります。年齢制限がなく、毎年贈られ、賞金もノーベル賞に近い規模です。こちらは生涯の業績を評価する性格が強くて、専門家のあいだではフィールズ賞と同等、場合によってはそれ以上に権威があると見られることもあります。

私が面白いと思ったのは、数学という一見ひとつの世界のなかにも、「若くして革命を起こした人を讃えるゲーム」と「長い時間をかけて偉大な仕事を積み上げた人を讃えるゲーム」が並んで存在しているということでした。同じ数学者でも、どちらのゲームに置かれるかで評価のされ方が変わる。

稼げる国と、数学が強い国は別だった

次に出てきた指摘が、私にはいちばん刺さりました。アーベル賞の受賞者を眺めると、G7諸国や伝統的な数学強国に偏っていて、シンガポールのように1人当たりGDPが非常に高い国からはほとんど出てこない。

ここで、お金を稼ぐ能力と、純粋数学で歴史に残る成果を出す能力は、かなり別物だという事実が浮かび上がります。

シンガポールのような国は、金融や貿易やハイテクで超効率よく稼ぐゲームに最適化されています。教育水準も高い。でもその優秀さは実利寄りの方向に向いています。

対してアーベル賞級の純粋数学が出てくるには、何世代にもわたる研究の伝統、優秀な人間が「金にならない研究」に人生を賭けても許される文化、世界中からトップ人材が集まってくる研究環境の蓄積が必要です。豊かになっただけでは、その知的な厚みはすぐには生まれない。豊かになった国が次に文化的・学術的な深みを作るフェーズに入るには、たぶん数十年単位の時間がかかります。

人はみんな違うゲームをしている

ここから話の抽象度が一段上がりました。

同じ「勉強」や「努力」に見えても、実際にはルールも得点の入り方も違うのではないか、という話です。

資本主義ゲームをやっている人は、稼ぐ・増やす・効率よく勝つがルールです。勉強も「役に立つから」やる。純粋知的探求ゲームをやっている人は、誰も解けなかった問題を解く、人類の知識のフロンティアを押し広げるがルールで、お金は二の次です。フィールズ賞やアーベル賞を取る人たちは、こっちのゲームで本気を出しています。

だから「何のために勉強してるのかわからない」と言われても、本人たちからすれば「わからなくて当然、それはあなたのゲームじゃないから」という話になる。

子育てゲームをやっている人は、ちゃんと育てて次の世代にバトンを渡すがルールで、成功の定義がまた全然違う。ほかにも権力ゲーム、名声ゲーム、趣味を極めるゲーム、ただ生きるゲームがあります。

どれが正しいわけでもない。ただ、ゲームが違うと同じ行動でも意味が変わるし、評価軸も変わる。日本でよく聞く「何のために勉強してるのかわからない」という感覚は、たぶん資本主義ゲームや受験ゲームの中で「役に立つかどうか」だけで測ろうとするから起きるのだと思います。でも世界には、役に立たないけど面白いから、誰もやっていないから、という理由で本気になっている人がいて、そういう人が時々歴史を動かします。

テレビゲームは何のゲームなのか

途中で出てきたこの問いが、私は好きでした。

テレビゲームやスマホゲームは、本質的には「制限された仮想空間で、明確なルールのもとにスコアや達成感を稼ぐゲーム」です。現実のゲームと違うのは、ルールが最初からはっきりしていること、死んでもリセットできること、目的が明示されていること、失敗のコストがほぼゼロなこと。

つまり、安全に「勝つ感覚」を味わえる練習場のような位置づけです。株が資本主義というリアルなサバイバルゲームなら、テレビゲームは完全に設計されたリスクの低い擬似ゲームだと言えます。

旅している人がバカに見える理由

旅ばかりしている人を「金を無駄にしている」と見てしまうのも、同じ構造だと思いました。自分が資本主義ゲームのルールで相手を採点しているから起きる現象です。

相手は世界を体験するゲームをしているだけなので、老後の資金や効率という基準は、そのゲームのスコアリングに最初から入っていません。だから無駄に見える。逆に旅している側からすれば、一生オフィスで数字だけ追っている人生はスコアが低すぎる、と見えるかもしれない。

みんな無意識に、自分がプレイしているゲームの評価軸で他人を測ってしまいます。資本主義ゲームの人は金を生まない行動を無駄だと言い、旅ゲームの人は体験しない人生を貧しいと言い、研究ゲームの人は論文にならない知識を軽視し、子育てゲームの人は家族を顧みない成功を空虚だと言う。

全部、自分のゲームのルールを世界の絶対ルールだと思い込んでいるだけなのだと思います。

次元が上がると、コスパの話になる

やりたいことが増えるほど、ゲームの次元が上がります。

お金だけなら1次元。お金と旅なら2次元。お金と旅とSNS発信と知識とフォロワー数とAIの理解を同時に追いかけたら、かなりの高次元になります。

次元が上がるほど、すべての軸を同時に最大化するのは難しくなる。だから「コスパ」「タイパ」という言葉が出てくるのだと思いました。あれは結局、自分が設定した複数のスコアを、限られた時間・金・体力でどう効率よく稼ぐかという話です。

自分が何のゲームをしているのかわからない、という感覚も自然だと思います。最初から「このゲームをやる」と決めている人は少なくて、なんとなく複数の軸を同時に動かしているうちに、だんだん自分のメインのスコアリング基準が固まっていく。高次元で複数の軸を追いかけるのは消耗しますが、それが楽しい人もいる。1つか2つに絞って深くやるのも、別種の強さだと思います。

それで、お金は重力なんじゃないか

ここまで書いて、私は自分の話に穴があることに気づきました。

ゲームは本当にバラバラなのか、ということです。

たぶん違います。お金はどのゲームにも、ある程度は必要です。研究するにも生活費が要る。旅をするにも要る。子供を育てるにも要る。純粋数学に人生を賭ける人も、食べないと死にます。

これは重力に似ていると思いました。電磁気の力は、電気を帯びたものにしか効きません。相手を選ぶ力です。でも重力は、質量があるものすべてに効く。どの方向にも、どの次元にも、選ばずに効いてしまう。

お金はそういう性質だと思います。ゲームの勝敗を決める主役ではないけれど、どのゲームの盤面にも背景として敷かれている。だから完全に無視することはできない。

健康は、スコアじゃなくて係数側にいる

そこまで考えて、もうひとつ思いつきました。同じように全部に効くものとして、健康があります。でもこれは重力とは役割が少し違う気がしました。

物理の理論には「力の強さそのものを決める場」というものが登場します。ディラトンと呼ばれるもので、その値が変われば重力の強さや空間の大きさまで変わってしまう。盤上の駒ではなく、ルールの係数の側にいるものです。

健康はそっち側なんじゃないかと思いました。お金が少なくてもゲームは進められます。でも健康が落ちると、同じ努力から返ってくる量そのものが小さくなる。スコアが減るというより、掛け算の係数が下がる感じです。

    研究ゲーム    旅ゲーム    子育てゲーム    稼ぐゲーム
        │           │            │            │
  ┌─────┴───────────┴────────────┴────────────┴─────┐
  │        お金（重力）＝どの軸にも効いてくる         │
  └────────────────────┬────────────────────────────┘
                       │
       健康（ディラトン）＝効き方の強さ自体を決める

　　お金は、どの次元にも漏れていく力。
　　健康は、その力の強さを決めるつまみ。

私が持ち帰ったこと

人はそれぞれ違うゲームをプレイしていて、ルールとスコアリングが違うから、同じ行動でも評価がまったく変わります。稼ぐゲームで上位にいる人と、純粋数学で歴史に残る仕事をする人と、世界を旅して体験を積む人と、子供を育てる人は、見た目は同じ人間でも、別のフィールドで別の勝ち方を目指しています。テレビゲームはそのリアルなゲームの安全な縮小版で、現代人は複数のゲームを同時にやろうとして高次元化し、その結果コスパやタイパという言葉で自分を測るようになる。

大事なのは、自分が今どのゲームを本気でやっているのかを自覚すること、そして他人が別のゲームをやっていることを認めることだと思います。そうしないと、自分のルールで他人を測り続けて、「こいつ何やってんだ」という疑問だけが永遠に残ります。

そのうえで私が付け足したいのは、お金と健康（とくに健康）はどのゲームでも下に敷かれているということです。この2つを自分のメインのスコアだと勘違いすると苦しくなるし、完全に無視すると盤面ごと沈む。主役ではないけれど、土台としては手を抜けない。

パーフェクトイド空間から始まった話が、気づいたら重力とディラトンの話になっていました。こういう脱線が、私はいちばん好きです。

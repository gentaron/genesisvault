# 【AI開発アイデア】重力波も天気予報の裏側も、全部タダで落ちてる。「公開データ」で世界をハックする22のすごいサイト

[[tag/無料]] [[tag/データリテラシー]] [[tag/重力波]] [[tag/AI個人開発]] [[tag/オープンサイエンス]] [[tag/公開データ]] [[tag/個人でできる研究]]

やあ。最近、勉強の一環で「公開されている科学データ」について調べてみたの。

そしたらね、もうびっくりするくらいヤバくてさ。
重力波の生データから天気予報の元ネタまで、全部ただで置いてあるの。

「こういうのは大学に所属してないと見れないんでしょ？ 申請書とか推薦状とか要るんでしょ？」
私もずっとそう思い込んでた。でも、違ったの。ページを開いて、ポチッと落とすだけ。思い込みで何年も損してた気がするから、今日はこの「誰でも使えるすごい道具」を、ラフに、でも真剣にまとめておくね。

「ここがすごい」だけじゃなくて、「で、結局これを使って何ができるの？」ってところまで噛み砕いておくから、安心して読んで。

🌌 1. 宇宙から降ってくるデータ

① 重力波の生データを拾い直す（GWOSC）

URL: `https://gwosc.org`

ここがすごい: ブラックホール衝突の瞬間の生データが、CC BY 4.0（出どころを書けば自由に使ってOK）で公開中。

で、何ができる？ Pythonで「探したい波形」を重ねるだけ。コーヒーが冷める前に、宇宙の出来事を自分のPCで見つけ直せる。「見つからなかった」ことを証明するだけでも、立派な発見になるよ。

② 加速器の衝突を自分で数える（CERN Open Data）

URL: `https://opendata.cern.ch`

ここがすごい: 5ペタバイト超の実データが9つの実験分、無料で公開されている。

で、何ができる？ 教科書の綺麗な絵じゃなくて、粒子が壊れていく「本物の数字」を自分で数えられる。物理の感覚が研ぎ澄まされるよ。

③ 今夜の空の「異変」を受け取る（Rubin Observatory / ALeRCEなど）

URL: `https://rubinobservatory.org` （ブローカー例: `https://alerce.online`）

ここがすごい: 星が急に明るくなったり消えたりした報せが、申請なしでリアルタイムに届く。

で、何ができる？ 「自分だけが気にする条件」を書いて、残りのノイズを捨てる。「早く知る」ことより、「何を捨てるか」のセンスが光る遊び方。

④ 惑星を自分で見つける（Lightkurve）

URL: `https://lightkurve.keplerscience.org`

ここがすごい: 宇宙望遠鏡が撮り続けた星の明るさの記録が、そのまま手元に来る。

で、何ができる？ 星の前を惑星が横切るときの「ほんの少しの明るさの落ち込み」を探す。すでに発見された惑星を追体験するだけでも、最初は十分ワクワクするよ。

⑤ 星の名前から全情報を引き寄せる（Astroquery）

URL: `https://astroquery.readthedocs.io`

ここがすごい: 星の名前や座標を投げるだけで、いろんな観測所のカタログを横断して返してくれる。

で、何ができる？ 「この星について人類が持っているもの」を一度に並べる贅沢。研究や観察の入り口に最適。

⑥ ガイア衛星の次期データを待つ（Gaia DR4）

URL: `https://www.cosmos.esa.int/web/gaia`

ここがすごい: 2026年12月2日に、星の位置を何年も追いかけた時系列データが公開予定。

で、何ができる？ 出た瞬間に触れる準備をしておく。半年後にニュースで知る人とは、見える世界と使えるデータの質がまるで違うはず。

🌍 2. 地面と空のデータ

⑦ 地震計の生波形を落とす（ObsPy）

URL: `https://obspy.org`

ここがすごい: 認証なしで世界中のデータセンターに繋がり、過去の波形も指定して落とせる。

で、何ができる？ 自分の住んでいる場所の下で何が起きているかを、ニュースの解説を挟まずに「生」の波形で見る。

⑧ 衛星画像を月12テラバイト（Copernicus Data Space）

URL: `https://dataspace.copernicus.eu`

ここがすごい: 無料アカウントで月12TBまで画像を落とせる。画像処理の枠も月1万単位で付いてくる。

で、何ができる？ 田んぼでも屋根でも港でも、同じ場所を何年分も並べれば、変化は目で見てわかる。自分の町の歴史や環境変化が読めるよ。

⑨ 天気予報の「元ネタ」を読む（ECMWF）

URL: `https://www.ecmwf.int`

ここがすごい: リアルタイムの予報カタログが丸ごとCC-BY-4.0で開放されている（結論じゃなくて、格子ごとの数値）。

で、何ができる？ 予報の裏にある計算式の数値をいじれる。AI予報の元データも同じように手に入る。

⑩ 予報の「外れ方」を貯める（Open-Meteo）

URL: `https://open-meteo.com`

ここがすごい: 登録なしで1分600回まで叩ける無料API。

で、何ができる？ 予報と実際の観測を毎日突き合わせる。「この土地はいつも風を強めに出す」みたいな、自分だけの「土地の癖」データが作れる。これは農家や漁師さんにとって、すごく価値があるはず。

🧮 3. 計算そのものが降りてきた

⑪ 量子コンピュータを実機で叩く（IBM Quantum）

URL: `https://quantum.ibm.com`

ここがすごい: 無料プランで本物の量子コンピュータが28日ごとに10分使える。

で、何ができる？ 10分は短いけど、素朴な回路なら何十回も回せる。SFの世界を自分のブラウザで体験できる。

⑫ 量子の誤り訂正をシミュレートする（Stim）

URL: `https://github.com/quantumlib/Stim`

ここがすごい: 量子の誤り訂正符号を普通のパソコンで大量に回せる無料シミュレータ。

で、何ができる？ 実機の10分より、こっちで基礎を固めたほうが、よっぽど量子の本質を学べる。

⑬ 数学の証明を機械に読ませる（Lean / mathlib）

URL: `https://lean-lang.org`

ここがすごい: 書いた証明が正しいかどうかを機械が判定してくれる。フェルマーの最終定理の形式化計画も進行中。

で、何ができる？ 数学の共同作業に、名前のない人が参加できる。「合っている気がする」から「機械が保証する正しさ」へステップアップできる。

⑭ 数式を厳密に計算する（SymPy）

URL: `https://www.sympy.org`

ここがすごい: 微分も積分も因数分解も、近似ではなく「厳密に」返してくるPythonライブラリ。

で、何ができる？ 手で解くのをやめて、計算を機械に任せる。Leanと組み合わせれば、証明の信頼性が段違いになる。

⑮ 新素材を事前に検索する（Materials Project）

URL: `https://materialsproject.org`

ここがすごい: 無料アカウントで、ある性質を持つ物質を条件で絞って検索できる。

で、何ができる？ 実験や購入の前に、「そもそもそんな物質、存在するの？」をデータベースで先に調べられる。無駄な足踏みが減るよ。

🛠️ 4. データを「形」や「音」にして、世界に置く

⑯ データを3Dの形にする（build123d / CadQuery）

URL: `https://github.com/gumyr/build123d`

ここがすごい: コードで立体を書ける。地形でも星の分布でも、3Dプリンタに渡せる形に整えられる。

で、何ができる？ 目で見て分からなかったものが、手で触ると分かることがある。データを「物体」に変換する魔法だよ。

⑰ データを「音」にする（Soundfile / Librosa）

URL: `https://librosa.org`

ここがすごい: 時系列データをそのまま音に落とせる。

で、何ができる？ 重力波の波形も、地震も、予報の外れ方も「音」で聞く。耳は目より周期の乱れに敏感だから、グラフで見逃した異常に気づけることがあるの。

⑱ 作ったものを世界に置く（Zenodo）

URL: `https://zenodo.org`

ここがすごい: 自分が作った表や図を、出どころ付きで公開の置き場に置ける。

で、何ができる？ 誰にも読まれなくてもいい。置いた瞬間に、それは「引用できる正式なデータ」になる。趣味と仕事の境界線が溶ける瞬間だよ。

来た、見た、勝った。

先読みをひとつ。
「データが開いたからって、みんなが急に研究者になるわけじゃない」。
開いているのはデータだけで、「何を問うか」は開いていないから。

実際、私もデータを落とすところまではすぐ行けて、そこから2週間くらい何も思いつかなかった。
詰まるのはいつも入口じゃなくて、その次の「問い」を立てるところにあるの。

それでもね、扉が開いているのに「閉じている」と思い込んでいる状態だけは、もったいない。
落とすのは今日できる。問いは、そのあとゆっくり探せばいい。

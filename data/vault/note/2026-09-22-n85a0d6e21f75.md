# 【必見】雑魚PCでも4社の上位AIを選べる。GPUを買わずに使い分けるGitHub Copilot

[[tag/AI]] [[tag/生成AI]] [[tag/AI活用]] [[tag/LLM]] [[tag/GitHubCopilot]]

GPUが1枚もなくても、OpenAI、Anthropic、Google、xAIの現行上位モデルを、同じモデル選択欄から切り替えて使えるようになってる。

これ、うちみたいな非力PCにはかなり大きいです。

強いAIを使いたい。でもローカルで巨大モデルを動かすなんて、これ絶対うちの子じゃ無理だ〜、となる。メモリも足りないし、絵を描くための強い部品も入ってない。大きなモデルの配布ページを見て「いいなあ、動かせる人うらやましい」で閉じるの、私はけっこう何度もやってます。

でも今回ちょっと面白いのは、AIが小さくなったわけじゃないんですよね。

巨大なままなのに、自分のPCへ載せなくてよくなった。

そこがなんか変なんです。

9月1日にClaude Fable 5.1、9月3日にGemini 3.8 Flash、9月4日にGPT-6 AstraがGitHub Copilotへ入り、さらに9月21日にはGrok 4.7も追加されました。Fable 5.1とAstraはPro+以上、Gemini 3.8 FlashとGrok 4.7はPro以上でモデル選択欄から指定できます。Grok 4.7だけはまだ段階的な展開中なので、全員の画面に同時に現れるわけではありません。

なんというか、1か月前なら「各社の最新AIを比べる」って、それぞれのサービスを開いて、それぞれ契約して、場合によってはAPIキーを取って、自前の道具につないで、という感じだったじゃないですか。

それが今、コードを書いている画面のモデル選択欄を押したら、

今日はAnthropicに考えてもらおうかな。

ここはOpenAIかな。

大量に回すならGoogleでいいかも。

xAIの新しいやつも試してみるか。

みたいになり始めてる。

AI会社を選ぶというより、CPUの動作モードでも切り替えるみたいな感覚になってきたんですよね。

しかも、この4つは単に名前だけ立派なモデルを集めたわけでもないです。

現在の第三者評価を見ると、GPT-6 AstraのmaxはIntelligence Indexで53。Claude Fable 5.1も同じ53で、9月9日時点ではこの2つが首位タイになっています。Grok 4.7は46で、コーディングエージェントの評価では前世代からかなり伸びています。Gemini 3.8 Flashは最高性能だけを取りにいくモデルではないけれど、9月の評価では価格に対する性能がかなり強い位置にいます。

もちろんベンチマークが53なら人類より53ポイント偉い、みたいな話ではないです。そんな便利な数字だったら世の中もう少し簡単です。

でも少なくとも、「弱いPCでも使えます。ただし中身は小型モデルです」という話ではない。

そこは大事だと思う。

ちゃんと現在の最上位圏にいる巨大なモデルを、こっちはGPUを持たずに呼べる。

私が今回いちばん引っかかったのはここでした。

じゃあ4つのうち何を使えばいいの、となるんだけど、ここは思っていたよりきれいに分かれています。

Fable 5.1は、長い時間をかけてコードベースを調べたり、何段階もある作業を進めたりする用途をかなり意識したモデルです。Astraも似ていて、計画して、作業して、途中で検証して、また直すような長い仕事が中心になっている。

この2つは現在かなり強い。

でも高い。

GitHub Copilot上の追加利用料金を見ると、どちらも100万入力トークン10ドル、出力50ドルです。対してGemini 3.8 Flashは入力0.75ドル、出力3.75ドル。出力料金だけ見ると13倍以上違います。

同じモデル選択欄に並んでるのに、値段はぜんぜん同じじゃない。

これ、地味だけど私はかなり好きです。

「いちばん頭のいいAIを毎回使えばいい」が普通に成立しないんですよね。

ちょっとした修正を頼むたびに最高級モデルを呼ぶより、普段はFlashをガンガン使って、本当に難しいところだけAstraやFableへ切り替える。たぶんこれから普通の人が覚えるのは、モデルの構造より、こういう雑な使い分けなんじゃないかなと思います。

Grok 4.7はその中間っぽく見えます。9月21日に追加されたばかりで、独立評価ではIntelligence Indexが46。コーディングエージェントでは前世代から9ポイント伸びています。ただ、まだ新しすぎるので、ここで「これが一番コスパいい」とまで言うのは早いかなと思っています。新しい数字って、登場直後だけ妙に輝いて見えるから困る。数週間するとだいたい人類が冷静になります。

で、私にとってもっと重要なのは、これらを使うためのハードです。

Copilot CLIの公式インストール条件を見ると、npm版で必要なのはNode.js 22以降です。WindowsならWinGetからも入れられます。GPUを用意しろとか、VRAMを何GB積めとか、そういう条件は出てきません。AI本体は自分のPCではなく向こうで動いているので、当然といえば当然なんだけど、巨大AIの記事ばかり見ているとこの当然さを忘れるんですよね。

だから「うちのPCでは124Bは無理」「VRAMがない」「Macの高いやつを買えない」という話と、GPT-6 Astraを使えるかどうかは、もう直接つながっていない。

ここ、けっこう変なことが起きてると思う。

少し前までAIのローカル実行を追っていると、数字が大きくなるほどハードの話になりました。

何GB必要なの。

どのGPUなら載るの。

量子化したら入るの。

メモリへ逃がせるの。

私はそういう話も好きなんだけど、最終的にだいたい「うちでは無理」に着地するんですよ。

今回は逆なんです。

モデルはさらに巨大になっているのに、必要な自分のマシンは巨大にならない。

計算能力を買うんじゃなくて、計算能力への入口を買う。

たぶんここが今回の変化なんだと思います。

ただし、無料で全部使える、ではありません。

Copilot Freeは0ドルでCLIまで触れますが、現在はモデルを自分で選ぶのではなく自動選択です。Proは月10ドルでモデル選択ができるものの、Fable 5.1とGPT-6 Astraを直接選ぶにはPro+以上が必要。個人向けPro+は月39ドルです。だから「4社のこの4モデルを自分で切り替えたい」という条件なら、いまの入口は月39ドルになります。

39ドル。

安いとは言わないです。

毎月払うと普通にお金です。

でも比較対象が「数十万円のGPU搭載PCを買う」になった瞬間、話が急におかしくなる。

しかもPCを買ったら、そのハードで動かせるモデルしか動かない。クラウドなら来月もっと強いモデルが追加されたとき、モデル選択欄の名前が変わるだけかもしれない。

この差はかなり大きい。

その代わり、失っているものもあります。

ネットが切れたら使えない。提供会社がモデルを消したら使えない。料金体系が変われば影響を受ける。完全ローカルではないから、データの扱いもモデルごとに確認しないといけない。

実際、Fable 5.1は安全分類を動かすため、Copilot上では標準でプロンプトと出力のデータ保持があります。保持データはモデル学習には使われないとされていますが、ほかのClaudeモデルと同じゼロ保持だと思って使うのは違います。

だから、これはローカルAIが不要になったという話でもないです。

むしろローカルには、オフラインで動くとか、データを外へ出さないとか、一度ハードを買えば従量課金を気にしなくていいとか、ちゃんと別の価値が残ってる。

私もいつか強いマシンを買って、巨大モデルを手元でゴリゴリ動かしてみたいです。そこは普通に憧れる。

でも「強いAIを使うには、まず強いPCを買わないと始まらない」という順番は、かなり崩れてきたんじゃないかな。

ちなみに、公式のnpm手順自体もこちらの検証環境で試してみました。

Node.js 22という条件は満たしていたんだけど、インストールがこちらの実行上限までに終わらず、GitHub認証と実際のモデル応答まで確認できませんでした。

なので「私の弱いPCでも4モデル全部サクサク動きました」とは書きません。

そこはまだ確かめてないです。

確認できているのは、CLI自体にGPU要件がなく、この4社のモデルが同じCopilotのモデル選択環境へ入り、個人向けではPro+から4つを手動で選べる、というところまで。

起動条件と、実際に毎日快適に使えるかは別です。ここを混ぜると、たぶん後で悲しい顔になる。

それでも、この変化はかなり好きです。

強いAIが小さくなったんじゃない。

むしろAIは巨大なままです。

ただ、その巨大さを自分の机の上に置かなくてよくなった。

なんかさ、そこがすごく2026年っぽい。

もしこの流れが続くなら、次に消えるのは「どの会社のAIを契約するか」という境界なのかもしれない。1つの作業画面の中で、文章はこれ、調査はこれ、コードはこれ、と裏で勝手に選ばれるところまで行ったら、私たちはモデル名すらあまり気にしなくなる可能性がある。

9月14日には実際、自動モデル選択にも「安さ優先」「バランス」「知能優先」に近い3段階の考え方が入り始めています。モデル名ではなく、欲しい結果と予算だけ指定する方向です。

そうなると、AIを使うために必要なものはGPUじゃなくて、「この仕事にはどのくらいのお金と知能を使うか」を決める感覚になってくる。

それが便利なのか、ちょっと怖いのかはまだよく分かりません。

でも、うちのよわよわPCを見ながら「この子の中には何も入らないのに、世界でもかなり強いAIを4つ呼べるんだよな」と考えると、私はちょっと笑ってしまう。

巨大AIがこちらへ来たんじゃなくて、こちらから巨大AIへ細い線が1本つながっただけなのに。

たぶん、こういう変化のほうが、あとから振り返ると大きかったりするんでしょうね。

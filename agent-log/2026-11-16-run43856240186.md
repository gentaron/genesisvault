# 過去記事メモリの検索と再利用を追加

## やったこと

genesisvault の品質ゲート/台帳の近くに、過去に採用した記事の要約・タグ・良かった型を JSONL で保存し、新しい記事のテーマからタグ一致で関連メモリを引く小さな recall_memories 関数を追加してください。生成エージェントには上位3件を参考情報として渡せるようにし、重複テーマの回避と再利用を確認するテストを1本追加します。外部APIやベクトルDBは使わず、標準ライブラリだけで完結させてください。

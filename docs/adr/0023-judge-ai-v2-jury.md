# ADR-0023: 判断AI v2 — 記号審査 + 陪審（PoLL）+ 双対質問

- **Status**: Accepted
- **Date**: 2026-11-23

## Context

公開前の審査（Clef 審査）と企画の選定（Juno）は、Workers AI 無料枠の判断モデル Clef
1人に聞いていた。2026-11-13〜11-22 の記録（docs/gate-runs/2026-11.md）では:

- 「積立9年目の投資ルール見直し」（11/20）、「静止する僕のルール」（11/17）を**合格**にしていた
- veto 3項目は毎日 81〜93% で通り、落ちたことが無い（「はい」に寄っている疑い）
- 選定は 10日中 4日、確信度 0.55 未満で棄権していた

見逃しの原因はモデルの賢さではなく、**ミナが何者かを判断モデルが知らない**こと。
正典（投資歴・一人称）やタイトルの使い回しは、どれほど大きなモデルでも、渡されていない
事実は判定できない。

オーナーの要件は「世界最高峰の水準・最も軽く・最も無料で。モデルを入れてもよい」。

## Options

1. **大きな判断モデルに替える**（Prometheus 2 8x7B、CompassJudger-2 32B など）
   — 無料で動かせる場所が無い。CI に数十 GB を毎朝落とすのは「軽く」に反する。知らない事実は依然として見逃す
2. **小さな専用判定モデルを CI で動かす**（GLIDER 3.8B、Selene 1 Mini 8B を llama.cpp で）
   — 無料だが、毎朝 2〜5GB のダウンロードと CPU 推論で数分かかる。日本語の評価は未検証
3. **ルールで決まることはルールで決め、残りを無料の小さな判断モデルの陪審に聞く**（採用）

## Decision

3層にする（`src/lib/pipeline/clef-review.ts`、`src/lib/ai/jev.ts`）。

1. **記号審査**（0円・0ms・決定論）: 正典（投資歴・一人称・資産構成・金額）、禁止トピック、
   タイトルの使い回し。モデルに聞かない。判断モデルが使えない日も必ず走る
2. **陪審（Panel of LLM evaluators / PoLL, Verga et al. 2024）**: Clef と Clef-flash を同時に呼ぶ。
   - 審査: veto は**最も厳しい票**、その他は平均。veto の票が `jury.maxDisagreement` 以上割れたら判断不能＝不合格
   - 選定: 選択肢の分布を平均。2人の第1候補が割れれば確信度が自然に下がり、棄権に倒れる
3. **双対質問**: yes/no を正向き・逆向きの2問で聞き、`p = (p正 + (1 − p逆)) / 2`。
   両方に「はい」と答えるモデルは 50% に引き戻され、甘い veto が自動的に厳しくなる。
   逆向きの質問は同じ呼び出しに同梱するので、呼び出し回数は増えない

veto が落ちたら `clefReview.enforceVeto` で公開しない（mode=advisory でも）。

## Consequences

- 費用: 呼び出しは審査1回あたり陪審2人×1回（書き直し時は×2）、選定2回。Workers AI 無料枠
  （1日 10,000 Neurons）に収まる。新しい鍵・ダウンロード・依存は無い
- 見逃し: 11/13〜11/22 の公開記事10本を記号審査に通すと、7本で違反12件（9年目11・僕1）を捕まえる。
  旧 Clef はこの10本をすべて合格にしていた
- 誤検知: 引用の中の他人の一人称（「僕は〜」と彼が言った）は通す。正典の exclude で管理する
- 判断モデルの捕捉率そのものは `bun run gate:eval`（鍵が必要）で測る。verify には入れない（INV-004）
- 将来の選択肢 2（専用判定モデル）は、陪審の3人目として足せる形にしてある（`selection.jev.workersAiModels`）

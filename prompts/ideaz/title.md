# タイトル

公式＝異常な数字・事実 → 常識との矛盾 → 自分への接続。約束は一つに絞る。
語順＝読者の悩み → 具体的な制約 → 意外な答え → 固有名詞。固有名詞は後半に証拠として置く。

長いタイトル、固有名詞、専門用語そのものは禁止しない。データ上それらが失敗原因だとは言えない。
守るのは2点だけ。「約束が一つ」と「自分の何が変わるかが即座に分かる」。

避けるもの＝「【】」で囲む、「〜とは」「〜とは何か」、「解説します」、「〜について考えた」、日付だけの数字。これらは約束を運ばない。

書き換え例
- 「Spark-X2.5-4Bを解説」→「4Bなのに100万トークン入る。私のノートPCで本当に動くのか」
- 「llmfitとは何か」→「手元のPCでどのAIが動くか、1コマンドで全部判定できるようになった」
- 「新しいAI圧縮法」→「22MBまで小さくしたのに、答えが変わらない。何を消したのか」
